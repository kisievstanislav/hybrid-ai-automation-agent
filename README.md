# Hybrid AI Automation Agent

An enterprise-style automation project built to demonstrate modern test automation, AI-assisted workflows, API integration, and RPA concepts.

## Project Goals

- Playwright UI Automation
- API Testing & Integration
- Agentic AI
- Business Rule Engine
- Queue Processing
- Human-in-the-Loop
- Logging
- Reporting
- CI/CD
- UiPath / RPA concepts
- Mortgage-domain automation

## Technology Stack

- TypeScript
- Node.js
- Playwright
- Express / Fastify (planned)
- SQLite
- Prisma (planned)
- Zod
- Pino
- Vitest
- GitHub


## Project Structure

This project follows a pragmatic Clean Architecture approach and is being built module by module with enterprise best practices.
